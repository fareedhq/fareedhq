## `03 / OPERATING PRINCIPLES`

```text
DEFINE SCOPE  ──►  COLLECT EVIDENCE  ──►  VALIDATE  ──►  EXPLAIN THE FIX
```

- I test systems I own or have explicit authorization to assess.
- Scanner output is evidence to review, not automatic proof of a vulnerability.
- A reproducible finding matters more than a long list of uncertain alerts.
- A useful report explains impact, confidence, limitations, and remediation.
