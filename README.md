## Featured project

### [ShamTrace](https://github.com/fareedhq/ShamTrace)

An evidence-first web reconnaissance and security assessment CLI written in Python.

- Collects scoped HTTP, DNS, TLS, cookie, CORS, and header observations
- Keeps evidence, confidence, and limitations attached to findings
- Generates offline HTML, JSON, and Markdown reports
- Designed for systems you own or are authorized to assess

```bash
shamtrace scan https://authorized-target.example --authorized --pages 3
```
